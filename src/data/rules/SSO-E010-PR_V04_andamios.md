# E-010-PR V_04 — Estándar para Armado y Uso de Andamios para Trabajos de Altura
**Versión:** 04 | **Tipo:** SSO — Estándar de Riesgo Crítico  
**Aplica a:** Procedimientos y matrices SSO que involucren uso de andamios  
**Triggers:** andamio, andamios, scaffolding, plataforma de trabajo en altura

---

## Reglas para el Procedimiento de Trabajo

| ID | Requisito | NC si... |
|----|-----------|----------|
| E010-R01 | Especifica que el andamio a utilizar es de tipo **prefabricado certificado** (ej.: Tipo Layher o equivalente certificado). Prohíbe el uso de andamios no certificados ("hechizos") | No especifica tipo certificado o no prohíbe andamios hechizos |
| E010-R02 | Describe el **sistema de tarjeta verde/roja** para habilitación/inhabilitación del andamio. La tarjeta verde debe indicar "**ANDAMIO OPERATIVO, APTO PARA SU USO**" | No menciona tarjeta verde/roja ni la leyenda requerida |
| E010-R03 | Indica que se debe completar la **lista de chequeo R1-D-001-PEM** de inspección diaria del andamio antes de cada jornada de trabajo | No menciona el registro R1-D-001-PEM |
| E010-R04 | Para andamios que superen **5 metros**: indica uso obligatorio de **shock absorber** (amortiguador de impacto) adicional al arnés con doble cola de vida | El andamio supera 5 m y no indica shock absorber |
| E010-R05 | Para andamios de **3 cuerpos o más**: indica que se requiere memoria de cálculo estructural del andamio | No indica memoria de cálculo para andamios de 3+ cuerpos |
| E010-R06 | El procedimiento referencia explícitamente el estándar **E-010-PR V_04** en la sección de referencias | No referencia E-010-PR |

---

## Reglas para la Matriz SSO

| ID | Requisito | NC si... |
|----|-----------|----------|
| E010-M01 | Se identifican los peligros propios del uso de andamios (colapso, caída, derrumbe de andamio) | No aparecen peligros asociados al andamio |
| E010-M02 | Los controles específicos incluyen: andamio certificado Tipo Layher, tarjeta verde/roja, inspección diaria R1-D-001-PEM | Los controles no incluyen estos requisitos del estándar |
| E010-M03 | El estándar E-010-PR V_04 aparece referenciado en las medidas de control | No aparece E-010-PR en controles |
